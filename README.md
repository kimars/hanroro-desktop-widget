# 한로로 바탕화면 위젯

Windows 바탕화면용 시계·메모·달력·음악·가구 꾸미기 앱입니다.

[최신 설치 파일 다운로드](https://github.com/kimars/hanroro-desktop-widget/releases/latest/download/HanroroWidget_Setup_x64.exe)

## 설치

Windows 11 64비트용 설치 EXE를 실행합니다. Python을 따로 설치할 필요가 없습니다. 시작 메뉴와 바탕화면 바로가기, 앱 제거 기능을 제공합니다.

현재 설치 파일은 코드 서명되지 않아 Windows 보안 경고가 나타날 수 있습니다.

## 업데이트

1.3.0부터 설정 → 업데이트에서 새 버전을 확인하고 업데이트를 누를 수 있습니다. 다운로드와 SHA-256 검증 후 설치하고 다시 실행합니다. 메모·설정·가구 배치는 유지됩니다. 자동 확인을 켜면 앱 시작 시 및 6시간마다 확인하며, 설치는 사용자가 버튼을 눌렀을 때만 진행합니다.

1.2 이하 버전은 이번 설치 파일을 한 번 직접 설치해야 합니다.

## 주요 기능

- 시계, 메모·할 일, 개인 달력
- Windows 음악 앱 정보와 재생 제어, 재생바 위 오디오 비주얼라이저
- CPU·RAM·지원 NVIDIA GPU 사용량
- 집중 타이머와 사용자 알람 파일
- 가구·소품 25종과 사진 액자, 이동·회전·크기·겹침 순서·고정
- 조명 줄·식물 잎·커튼 등의 부분 애니메이션
