# 한로로 바탕화면 위젯

[Windows 설치 파일 다운로드](https://github.com/kimars/hanroro-desktop-widget/releases/latest/download/HanroroWidget_Setup_x64.exe) · [변경 내역](https://github.com/kimars/hanroro-desktop-widget/releases)

설치형은 HanroroWidget_Setup_x64.exe 하나를 실행합니다. 설치 후 시작 메뉴 또는 바탕화면 아이콘을 사용하세요. Windows 설치된 앱 목록에서 제거할 수 있으며 사용자 메모·설정·사진은 유지됩니다.

Windows 11 x64용 바탕화면 위젯입니다. 실행용 ZIP은 압축을 전부 풀고 EXE를 실행합니다. EXE와 _internal 폴더를 함께 보관하세요. 업데이트할 때는 이전 앱을 종료하고 새 폴더의 EXE를 실행하세요. 설정과 메모는 앱 폴더와 별도로 보관합니다.

## 가구 · 사진

설정의 가구 · 사진에서 가구/수납/조명/식물/소품/패브릭 · 벽 분류를 골라 추가합니다. 가구와 소품 25종, 사용자 사진 액자를 지원합니다. 바탕화면에서 배치를 누른 뒤 물건을 드래그합니다. 물건을 클릭하면 크기·회전·반전·앞뒤·고정·삭제 도구가 표시됩니다. 잠근 물건은 설정 목록에서 고정을 해제할 수 있습니다.

펜던트 조명과 스탠드 줄, 커튼, 식물 잎, 전구 가랜드, 촛불, 선풍기는 본체와 움직이는 부분을 따로 그립니다. 배치 편집 중과 전체 애니메이션을 끈 경우에는 멈춥니다. 각 물건의 움직임 스위치로 개별 정지도 가능합니다. 책상·의자·수납장 등은 고정입니다.

## 음악 · 타이머

Windows 미디어 제어를 지원하는 음악 앱의 재생 정보를 가져옵니다. 오디오 막대는 재생바 바로 위에 표시하며 실제 기본 출력 장치의 소리를 분석합니다. 마이크를 사용하거나 녹음 파일을 저장하지 않습니다. 별도 오디오 창과 LP 위의 막대는 없습니다.

집중 타이머는 기본 알람음이나 직접 고른 MP4/음악 파일을 사용합니다. 공연 카운트다운은 제거했습니다. 일반 달력과 개인 일정은 계속 사용할 수 있습니다.

## 배포

실행 파일 회사명은 마스이며, 공개 신뢰 Authenticode 인증서는 제공되지 않아 현재 파일은 서명되지 않았습니다. SmartScreen 경고가 남을 수 있습니다. 검증된 게시자는 신뢰되는 코드 서명 인증서로 서명해야 표시됩니다. 인증서가 있는 경우 distribution/SignRelease.ps1을 사용할 수 있습니다.

소스에서 Windows EXE를 만들려면 build_exe.bat를 사용합니다. 준비된 실행용 ZIP에는 Python 설치가 필요하지 않습니다.


## 자동 업데이트

설정 → 업데이트에서 새 버전을 확인하고 업데이트를 누릅니다. 다운로드 진행률을 표시하며, 취소할 수 있습니다. 파일 크기와 SHA-256을 검증한 뒤 설치하고 앱을 다시 실행합니다. 앱 실행 후 및 6시간마다 새 버전을 자동 확인하며, 자동 확인 스위치로 끌 수 있습니다. 자동 확인만으로 설치하지 않습니다. 사용자 설정은 유지합니다.

공개 GitHub Releases의 버전과 설치 파일을 사용하며 GitHub 계정이나 비밀번호가 사용자 앱에 필요하지 않습니다. 배포 저장소는 release_info.py에서 지정합니다. 설치 파일의 Windows 보안 경고를 끄거나 우회하지 않습니다. 기존 1.2 버전에는 자동 업데이트가 없으므로 이번 버전을 한 번 설치해야 합니다.

새 버전을 배포할 때 release_info.py의 VERSION을 올리고 설치 파일을 만든 뒤 distribution/release/publish.py로 SHA-256 파일을 준비합니다. 설치 EXE와 .sha256 파일을 같은 v버전 GitHub Release에 올립니다. GitHub CLI로 게시하려면 명시적으로 --publish를 지정합니다.

## 사진 배경 순환

배경 설정에서 사진을 여러 장 선택하거나 끌어 놓습니다. 목록 오른쪽에서 사진마다 표시할 초(1~86,400)를 정하고 위로·아래로 순서를 바꿉니다. 사진 순환 스위치로 켜고 끕니다. 전체 화면 작업 중에는 순환도 멈추며, 돌아오면 남은 시간부터 재개합니다. 영상 모드에서는 사진 순환이 멈춥니다.

## GitHub 배포 빌드

전용 저장소의 Windows release 작업이 Windows에서 설치 파일을 만들고, 성공한 빌드만 GitHub Releases에 게시합니다. release_info.py의 VERSION을 올려 커밋하면 새 배포가 시작됩니다. 설치 EXE와 SHA-256 파일이 함께 게시됩니다.

## 업데이트 알림과 자동 설치

설정 → 업데이트에서 자동 다운로드 · 설치를 켭니다. 새 버전이 확인되면 바탕화면 왼쪽 아래에 배경 없는 인물과 말풍선이 위젯 앞에 나타납니다. 15초 뒤 다운로드·검증·설치를 시작하고, 메모 입력·배치 편집·대화상자 사용 중에는 기다립니다. 나중에를 누르면 해당 버전의 자동 설치를 이번 실행 동안 미룹니다. 알림 미리보기는 실제 다운로드나 설치를 실행하지 않습니다. 일반 앱 창 위로는 올라가지 않습니다. Windows 보안 확인이 필요한 경우에는 정상적인 확인 절차를 따릅니다.

배포 빌드는 assets/integrity.json에 기록한 원본 크기와 SHA-256을 확인합니다. 기본 자료를 의도적으로 교체할 때는 해당 항목도 함께 갱신합니다. 전송 후 Git blob SHA와 원본 SHA가 일치하는지 확인해야 합니다.


### 설정과 밤 조명
설정 메뉴는 시작·화면 / 배경 / 위젯 / 바로가기 / 가구·사진 / 업데이트입니다.
음악 연결·메모·일정·집중 타이머는 위젯 화면, 백업은 시작·화면에서 엽니다.
다크 모드는 시작·화면에서 켜며 직접 지정한 색은 유지됩니다.
위젯 → 밤 조명에서 조명 효과를 켭니다. PC 시간 기준 19시부터 다음날 07시까지 작동합니다.
1.6.2에서 날씨 창문·자동 위치 감지·외부 날씨 조회를 제거했습니다. 기존 설정에 날씨가 켜져 있어도 업그레이드 후 제거됩니다.

### 1.6.1 자동 알림
Windows 실행 5초 후와 이후 60초마다 공개 최신 릴리스의 HEAD 리다이렉트를 확인합니다. 새 태그일 때만 REST API로 설치 파일과 해시를 확인합니다. GitHub/네트워크 반영 시간만큼 지연될 수 있으며 실시간 푸시는 아닙니다. 네트워크 실패 시 1·2·4·8·15분 간격으로 재시도합니다. 자동 확인을 끄면 주기 조회하지 않습니다. 다운로드·설치 중이거나 이미 새 버전을 알린 경우 상태를 유지합니다. 1.6.0 이하 설치본은 이번 수정본을 한 번 설치해야 새 간격이 적용됩니다.


### 1.7.0 독 · 검색 · 4K
- 시작·화면 → 독·검색: 맥 스타일 독(기본 켜짐), 자동 숨김, 작업 표시줄 숨김(기본 꺼짐), Windows 키 검색(기본 꺼짐).
- 독은 바탕화면 적용 중에만 표시합니다. 앞의 12개 바로가기와 최대 6개 추가 실행 앱을 표시하며, 나머지 바로가기는 검색에서 찾을 수 있습니다. 실제 앱 아이콘은 Windows 바로가기에서 가져옵니다.
- Win 단독 키는 선택 옵션을 켠 동안 검색으로 연결합니다. Win 조합 키는 재전달하며 입력을 저장하지 않습니다. 관리자 앱·게임·다른 키보드 유틸리티 환경에서 실제 동작 확인이 필요합니다. 원래 Windows 기능으로 돌아가려면 옵션을 끄거나 앱을 종료합니다.
- 숨김/키 연결은 레지스트리를 바꾸지 않습니다. 네이티브 보조 프로세스가 부모 종료를 감시하며 원래 표시되던 Explorer 작업 표시줄만 복원합니다. 정상 종료 시 중지 이벤트로 즉시 복원합니다.
- 검색은 설치된 앱 목록을 5분 캐시하고 280ms 입력 대기 후 파일을 검색합니다. Windows Search 인덱스를 사용하며 실패하면 바탕 화면·문서·다운로드의 직접 자식 최대 2500개를 확인합니다. 검색어와 결과는 외부로 전송하지 않습니다.
- 배경 → 4K 고화질(기본) / 화면 해상도. 16:9는 3840×2160, 세로·울트라와이드는 화면 비율을 유지해 긴 변 3840픽셀로 출력합니다. 원본 파일은 수정하지 않고 해시 이름으로 보관합니다. 영상은 원본을 유지하며 재인코딩하지 않습니다. 저해상도 사진의 새 디테일 생성/AI 복원 기능은 아닙니다.
- 복사/해시/이미지 렌더를 백그라운드에서 처리합니다. 배경 렌더는 실행 1개 + 최신 대기 1개로 제한하고 PNG는 임시 파일 후 원자 교체, 생성 캐시는 8개로 제한합니다. sRGB 변환과 부드러운 확대/축소를 사용합니다.


### 1.7.1 안정화
- 독은 위젯 링크 대신 Explorer 작업 표시줄의 Appid 버튼을 UI Automation으로 읽습니다. 표시 좌표가 유효하면 좌→우 순서를 사용하고, 숨겨진 상태라 좌표를 알 수 없으면 공급자 순서를 유지합니다. 조회가 끝나기 전에는 기존 작업 표시줄을 숨기지 않으며, 실패하면 유지하고 app.log에 기록합니다.
- 앱 수를 12/6개로 자르지 않습니다. 화면 폭을 넘으면 이전/다음과 휠로 전환합니다. 실제 창 목록은 HWND별로 보관해 같은 프로세스의 여러 창도 선택합니다. 이미 종료됐거나 PID가 달라진 창은 실행하지 않습니다.
- 기존 위젯 바로가기 패널을 복구했습니다. 독은 non-topmost, desktop-owned, no-activate이며, Windows 메시지에서 임의 z-order 변경도 막습니다.
- Windows 키는 새 시작 화면을 엽니다. 빈 검색은 설치 앱 전체 목록, 입력 후에는 앱·파일 검색입니다. 작업 표시줄 숨김과 키 연결은 shellRevision 2로 한 번 이전하며 설정에서 다시 끌 수 있습니다.
- 반복 COM 조회 대신 캐시와 WinEvent 갱신을 사용합니다. 숨겨진 독은 정기 창 조회를 생략합니다. 시작 화면은 보이는 행의 아이콘만 읽습니다.
- 업데이트는 공개 update-feed.json을 먼저 확인하고, 실패하면 GitHub API로 확인합니다. 자동/수동이 같은 함수를 쓰며 HEAD 전용 조회는 제거했습니다. 피드는 설치 파일·체크섬 업로드 후에만 CI에서 게시합니다. 오류는 app.log와 업데이트 설정의 자동 확인 상태에 표시합니다.
