- 화면 아래 독: 마우스 확대, 자동 숨김, 바로가기와 실행 중 앱 표시
- 검색창에서 앱·파일 검색과 실행, 열려 있는 앱 전환
- 시작·화면 → 독·검색에서 Windows 키 연결과 기존 작업 표시줄 숨김 선택
- 작업 표시줄은 원래 보이던 것만 복원, 앱 비정상 종료 때도 별도 복원 프로세스가 처리
- 사진 배경은 원본을 보존하고 기본 4K PNG 출력, 화면 해상도 모드도 선택 가능
- 원본 복사·4K 렌더·앱 검색을 화면 조작과 분리
- 크림·살구·연한 하늘색 기본 위젯과 핑크 포인트, 사용자 지정 위젯 색 유지

독은 바탕화면 적용 상태에서 표시됩니다. 기본 작업 표시줄 숨김과 Windows 키 연결은 기본 꺼짐입니다. 파일은 Windows 검색 인덱스를 사용하며 사용할 수 없으면 바탕 화면·문서·다운로드 폴더에서 찾습니다.
작은 사진을 4K로 확대해도 원본에 없는 디테일이 복원되지는 않습니다. Windows 키와 실제 Explorer 동작은 PC 환경에 따라 확인이 필요합니다.
Windows x64용이며 코드 서명되지 않은 파일입니다.
