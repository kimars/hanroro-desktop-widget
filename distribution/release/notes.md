자동 업데이트 알림을 더 빨리 표시합니다.

- 실행 5초 후, 이후 1분마다 백그라운드에서 새 버전 확인
- 설정창을 열지 않아도 바탕화면 인물·말풍선 알림 표시
- 평소에는 공개 최신 버전 주소만 확인하고, 새 버전일 때만 상세 정보 조회
- 통신 오류 시 점진적으로 재시도, 이미 받은 설치 파일과 알림 유지

이 버전을 한 번 설치하면 다음 배포부터 적용됩니다. 푸시 방식이 아니므로 네트워크·배포 반영에 따라 표시가 늦어질 수 있습니다.
자동 다운로드·설치는 기존 설정을 따릅니다. Windows x64용이며 코드 서명되지 않은 파일입니다.
