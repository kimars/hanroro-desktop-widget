## 한로로 바탕화면 위젯 1.7.2

- 독이 바탕화면 클릭 후에만 나타나던 표시 조건 수정. 기본값은 항상 표시이며, 최대화 창이 독을 가리지 않도록 Windows AppBar 영역을 예약합니다.
- 앱 원본 아이콘 조회 개선. 앱 ID, 실행 파일, 실제 창 아이콘을 사용합니다.
- 앱 이름 표시와 여러 창 선택 팝업 추가. 바로가기와 실제 실행 파일을 함께 대조합니다.
- Windows 조회 작업을 시간 제한이 있는 별도 프로세스로 이동. 설정·입력 UI가 느린 Windows 응답을 기다리지 않도록 개선했습니다.
- 종료 후 남은 UI 타이머와 작업 프로세스 정리 강화.
- 기존 바로가기 위젯과 자동 업데이트 유지.

Windows x64 설치 파일입니다. 기존 설치 위에 설치할 수 있습니다.
