독·시작 화면과 자동 업데이트를 수정했습니다.

- 위젯 바로가기를 독 앱 목록으로 잘못 가져오던 동작 수정
- Windows 작업 표시줄 앱 버튼 순서를 UI Automation으로 읽고, 공간이 부족하면 페이지·휠로 전체 앱 접근
- 여러 창이 열린 앱은 창 제목별 선택 목록 표시
- 빠졌던 기존 위젯 바로가기 버튼 복구
- 독의 항상 위 설정 제거, 다른 창 위로 올라오지 않도록 바탕화면 층에 고정
- Windows 키로 전체 앱 목록·검색을 여는 시작 화면, 원래 작업 표시줄 숨김 연결 기본 적용
- 순서 조회 실패 시 원래 작업 표시줄을 유지해 실행 경로 보존
- 반복 프로세스·COM 조회를 캐시하고 창 변경 이벤트 중심으로 갱신
- 화면에 보이는 앱 아이콘만 읽고, 연결된 음악 앱이 일시정지 상태면 오디오 분석 중단
- 자동/수동 업데이트 조회를 동일한 공개 배포 정보 경로로 통일, 자동 확인 시간·실패 사유 표시

Windows 작업 표시줄 순서와 키 입력의 실제 동작은 Windows 빌드·사용 중인 다른 유틸리티에 따라 확인이 필요합니다. 기존 독 설정은 새 시작·작업 표시줄 연결로 한 번 전환되며, 시작·화면 → 독·검색에서 끌 수 있습니다.
이전 설치본에는 이번 수정본을 한 번 설치해야 적용됩니다. Windows x64용이며 코드 서명되지 않은 파일입니다.
