업데이트 알림과 자동 설치를 추가했습니다.

- 바탕화면 왼쪽 아래, 위젯 앞에 인물과 말풍선으로 새 버전 알림
- 지금 업데이트 / 나중에, 다운로드 진행률 표시
- 설정 → 업데이트 → 자동 다운로드 · 설치 (선택 사항)
- 알림 후 15초 뒤 설치, 메모 입력·배치 편집 중에는 대기
- 알림 미리보기 버튼 추가
- 다운로드 작업이 끝난 뒤 설치를 시작하도록 처리 개선

이번 버전을 설치하면 다음 업데이트부터 새 알림을 사용할 수 있습니다. 메모·설정·가구 배치는 유지됩니다.
