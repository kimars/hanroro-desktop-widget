## 한로로 바탕화면 위젯 1.7.3

- 앱 아이콘 하나에 열린 창을 묶고, 아이콘 바로 위에 Windows DWM 창 미리보기를 표시합니다. 미리보기를 누르면 해당 창을 복원합니다.
- 내 폴더·문서·다운로드 바로가기와 열린 탐색기 창을 파일 탐색기 그룹 하나로 통합했습니다. 등록한 폴더는 그룹의 바로가기 메뉴에 유지됩니다.
- 기존 앱·웹사이트·기능 버튼을 하단 독으로 통합했습니다. 바탕화면의 중복 바로가기 패널은 숨겨집니다.
- 앱 로고의 임의 글자 아이콘과 색 배경을 제거했습니다. Windows 앱 ID, 실행 파일 및 창의 원본 아이콘을 사용합니다.
- 하단 독 영역과 위젯 영역을 분리하고 창 미리보기를 해당 앱 아이콘에 고정했습니다.
- 독의 바탕화면 소유 관계를 해제하고 숨김·최소화 복구, 실제 전체화면 상태 확인, Explorer 재시작 후 AppBar 재등록을 추가했습니다.
- 창 선택 시 느린 앱을 동기적으로 기다리지 않도록 개선했습니다.

Windows x64 설치 파일입니다. 기존 설치 위에 설치할 수 있습니다.
