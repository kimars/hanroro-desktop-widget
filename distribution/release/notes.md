밤 조명과 날씨 창문을 추가하고 설정창을 정리했습니다.

- 설정 메뉴를 6개로 정리하고 위젯 설정을 표시·배치 / 색상 / 밤·날씨로 분리
- 다크 모드가 설정창과 기본 위젯 색상에 함께 적용, 사용자 지정 색 유지
- 세로 색상 막대를 마우스로 고르는 원형 색상환으로 교체
- 밤에는 배경이 어두워지고 배치한 조명에 따뜻한 빛 표시
- 날씨 창문: IP 기반 대략적 현재 위치, 20분 자동 갱신, 도시 직접 선택 지원
- 비·눈·구름과 낮·밤을 창문에 표시, 애니메이션 끄기 지원

설정 → 위젯 → 밤·날씨에서 켤 수 있습니다. 날씨는 ipapi.co와 Open-Meteo를 사용합니다. 자동 위치는 VPN·통신망에 따라 다를 수 있습니다.
Windows x64용이며 코드 서명되지 않은 배포 파일입니다.
